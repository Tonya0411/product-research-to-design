# 设计调研方法指南（Design Portfolio）

> 调研不是为了展示资料，而是为了帮助设计做出正确决策。
> How to make a design portfolio?

---

## 一、为什么很多人的设计调研没有价值？

很多同学花了大量时间查资料，却依然无法支撑后续设计。真正的问题通常出现在以下几个方面：

- **调研目标模糊**，不知道到底想验证什么
- **信息堆积过多**，缺少筛选和归纳
- **数据之间没有联系**，无法形成逻辑
- **只有现象，没有分析与结论**
- **调研结果没有真正影响设计方案**

**核心原则：调研不是为了展示资料，而是为了帮助设计做出正确决策。**

### 反面→正面的四个优化动作（以"快递盒回收"为例）

| 动作 | 说明 | 示例 |
|------|------|------|
| **目标聚焦** | 避开宽泛背景，直击核心链路 | 直击快递盒生命周期链路，锁定"低回收率"核心症结 |
| **数据降维** | 只保留最关键的数据支撑 | 提取"网民基数、快递总量、极低回收率"三大核心数据支撑 |
| **因果叙事** | 建立强因果叙事链 | 运用生命周期模型建立"宏观背景——产业流程——分流对比——痛点剖析"的强因果叙事链 |
| **分流对比** | 通过对比剖析深层问题 | 通过"有序 vs 无序"对比，将表象问题深度剖析为三大社会系统痛点 |
| **决策生成** | 调研结论转化为行动 | 调研结论直接转化为设计任务书 |

### 案例：快递盒（Carton）生命周期研究

**BACKGROUND 背景**
- 双十一（Singles' Day）交易额：2019 268.4 billion → 2020 498.2 billion → 2021 540.3 billion
- 中国快递业务保持高增长：2017 40 billion 件 → 2018 50 billion 件 → 2019 60 billion 件
- 2021 年中国快递包裹量超 1000 亿件，产生 900 万吨纸类废物和 180 万吨塑料废物，包装废弃物回收率低于 **20%**

**RESEARCH 研究：The life of a courier box（快递盒的一生）**
- 生命周期：原材料获取（Chip wood to get raw materials）→ 纸浆制造 → 纸板加工（Orderly processing）→ 使用 → 废弃（Out of order processing ⚠️）
- **Why is carton recycling handled in disorder?** 三大痛点：
  1. **The recycling system is chaotic** — 回收体系混乱
  2. **Limitations of technical level** — 技术水平受限
  3. **Citizens have a weak awareness of environmental protection** — 公民环保意识薄弱

## 二、开始调研之前，先回答这 4 个问题

### WHAT（研究什么）
- 一个产品
- 一项服务
- 一个社会现象
- 一种文化内容

### WHY（为什么研究）
- 发现用户需求
- 找到设计机会
- 验证设计假设
- 了解行业现状

### WHO（研究谁）
- 用户
- 利益相关者
- 从业人员
- 专家
- 管理者

### HOW（如何研究）
- 访谈
- 问卷
- 文献分析
- 案例研究
- 数据分析

### 示例：智慧养老项目

- 发掘"智慧养老"宏观社会现象，明确研究主体不仅是"老年人"，还涵盖医护人员、社区管理者等利益相关者
- 对应底层趋势，直击行业与社会痛点
- 综合运用文献政策分析、老年人口宏观数据分析，配合"线上 / 多元化需求 / 线下"的场景研究

#### PSTP 设计背景（PSTP design background）
从四个维度建立背景认知：

| 维度 | 内容 |
|------|------|
| **民众（Popular）** | 健康意识的提升 → 老年人身体机能下降，疾病发生率上升 |
| **社会（Society）** | 人口老龄化加剧 → 老年人口数量逐年递增，养老压力上升 |
| **技术（Technology）** | 互联网 + 医疗发展 → 互联网、数字医疗、人工智能技术支持 |
| **政策（Policy）** | 政策与经济扶持 → 银发经济，国家战略支持 |

服务朝多元化方向发展，价值观念与生活方式上更加开放——**不单是养老，更是享老**。

#### Problem & Breakthrough 社区智慧养老现存问题
1. 服务内容单一
2. 信息沟通渠道不畅
3. 供不应求、供不符求
4. 老年人数字鸿沟

对应三大场景研究：**线上** / **多元化需求** / **线下**

## 三、一套完整的设计调研流程

> 不要把调研理解成"查资料"，它其实是一条连续的思考路径。

```
明确设计问题 → 收集相关信息 → 分类整理资料 → 提炼关键发现（Key Findings）
                                                            ↓
为后续设计提供依据 ← 寻找机会点（Opportunity） ← 输出设计洞察（Insight）
```

### Primary Research 一手调研示例（社区智慧养老服务）

**1. Questionnaire survey 问卷调查**
- 围绕"社区智慧养老服务"，发放 250 份问卷，有效填写人次 231 人
- 维度：身体状况 / 照护需求 / 服务满意度 / 消费意愿等
- 提炼关键词："生活照料"、"健康监测"、"紧急救援"等关键词出现次数最多

**2. Fieldwork 田野调查**
- 通过田野调查、问卷调研、访谈用户等方式，走访了湖北省多家典型智慧养老社区
- 调研地点：洪山区卓刀泉社区养老院、武昌区杨园街四美塘社区——杨园街智慧养老信息中心、武昌区水果湖北环路社区——康纳洲养老服务中心、狮子山街玫瑰湾社区
- 从设施设备、服务供给、活动组织等维度归纳现状
- 结论：目前社区养老服务存在"资源分配不均"、"技术安全风险"、"设备闲置风险"三大主要问题

**3. Semi structured user interviews 半结构式用户访谈**
- 对杨园街智慧养老信息中心的**社区工作人员、护工、老人家属、老年人**进行深度访谈
- 访谈信息：14 名受访者（18 名护工？45-80 岁，2 次…），覆盖护工 / 工作人员 / 家属 / 老人
- 半结构化访谈提纲 + 现场照片记录
- **触发后期设计规划**：用户访谈 → 整理逐字稿、关键的观点句 → 整理资料 → 计算机语言需求分析 → 扎根理论 → 用户旅程图 / 系统地图

## 四、调研方法可以这样组合

### 一手调研（Primary Research）
> 直接接触真实对象，获取第一手信息。

- ○ 用户访谈
- ○ 实地观察
- ○ 情境体验
- ○ 焦点小组
- ○ 问卷调查
- ○ 可用性测试
- ○ 行为记录

**特点：真实、针对性强，但成本较高。**

### 二手调研（Secondary Research）
> 利用已有资料建立背景认知。

- ○ 行业报告
- ○ 论文文献
- ○ 新闻资讯
- ○ 政府公开数据
- ○ 品牌官网
- ○ 竞品案例
- ○ 书籍
- ○ 专业数据库

**特点：获取效率高，适合建立整体认知。**

### 示例：香云纱（非遗面料）项目——二手 + 一手调研结合

**BACKGROUND 背景（二手调研）**
- **NO1. 香云纱历史**：香云纱，又名"响云纱""莨纱"，是广东佛山顺德的传统丝绸面料。以桑蚕丝织物为料，用薯莨汁浸染、河泥涂覆等复杂工序制成。外观古朴光泽、深色纹理，质感爽滑挺括。承载岭南文化，见证技艺传承，常用于传统服饰，现融入现代时尚，属国家级非遗。
- **NO2. 香云纱发展现状**：香云纱生产于中国顺德，据 2020–2024 年数据预测，香云纱产量呈逐年增长趋势（2020E → 2024E）。香云纱染整技艺是第二批中国国家级非物质文化遗产，我国作为香云纱的发源地，未来必将香云纱的文化推广至全球。

**RESEARCH 调研（一手调研为主）**
- **NO3. 香云纱染整技艺**：以桑蚕丝织物为坯，取薯莨块茎榨汁、特定河涌含铁矿泥为材。流程漫长：先反复浸薯莨汁、晾晒（阳光氧化固色），经多次封莨水加深色泽；再涂河泥（铁离子与单宁反应）、水洗，且全流程纯手工制作，对环境、气候要求严苛，需历经十数次重复工序，制作周期长达数月。
  - 工序流程：**薯莨 → 薯莨切开 → 薯莨捣碎 → 过滤薯莨汁/浸染 → 晾晒**
  - 整个过程不使用化学染料和助剂，是绿色环保的染整工艺，尽显传统技艺的独特坚守与生态价值。
- **NO4. 香云纱大众了解情况**：根据查阅的文献以及问卷调查（206 份有效数据）的结果，发现现代社会人群对于香云纱的各方面知识了解较少，且观众更喜爱于可以互动的传播形式，包括 AR、实拍视频、人物 IP 的创新等。
  - 基本不了解 25.7%
  - 稍微了解一些 36.2%
  - 知道但不了解 31.6%
  - 特别了解 6.5%

## 总结：一份有价值调研的检查清单

1. ✅ 开始前先回答 **WHAT / WHY / WHO / HOW** 四个问题
2. ✅ 一手调研 + 二手调研组合使用，互相验证
3. ✅ 沿着"**问题 → 信息 → 整理 → Key Findings → Insight → Opportunity → 设计依据**"的完整链路推进
4. ✅ 数据降维、因果叙事、分流对比，形成分析与结论
5. ✅ 调研结论最终转化为**设计任务书**，真正影响设计方案
